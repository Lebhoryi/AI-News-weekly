## 🔥 今日精选

🔴 **[MIT CSAIL / Hacker News]** 研究者发现大模型能直接读写神经网络权重，提出「权重空间编程」 — MIT CSAIL 团队发布《Sparks of Weight-Space Programming》：只看原始权重，GPT-6 Astra 就能判断网络被训练来做什么；在没有任何环境反馈的情况下从零写出小游戏网络，胜过大模型用 PPO 训练 1 亿步的版本；针对 Qwen3.5-0.8B 已知的推理循环问题，它原生修改 0.016% 的权重，MATH-500 从 7.9% 升至 48.1%，IFEval 提升 3 倍，且全程不许它写训练循环。作者认为，继 Adam、Muon 这类符号优化器之后，「会推理权重的 LLM」将成为下一代优化器。HN 讨论 1845 分。（[原文](https://rikiyat.github.io/blog/weight-space-programming/)）

🔴 **[The Decoder / 36氪]** Anthropic 三季度营收近 170 亿美元、同比增长 1127%，但净亏损 233 亿美元 — 据 Bloomberg 与 The Information，季度运营成本 175 亿美元已超过营收，其中包含 50 亿美元为锁定短期算力预付的费用；净亏损由去年同期的 121 亿美元扩大至 233 亿。招股书显示算力与数据中心租约承诺达 8950 亿美元，IPO 拟募资约 1000 亿美元，其中至多 35 亿来自日本投资者。收入十二倍增长与亏损同步放大，说明前沿实验室正用资产负债表换取算力。（[The Decoder](https://the-decoder.com/anthropic-grows-revenue-twelvefold-but-posts-23-billion-loss/)）

## 🌍 国际动态

🟡 **[CNBC / Hacker News]** Oracle 申请发行 200 亿美元股票与债券，为 AI 基建融资 — 募集资金将用于一般企业用途，可能包括资本开支、偿还债务与后续投资。AI 数据中心的融资方式正从科技巨头自有现金，转向公开市场与债务工具，杠杆开始进入这条产业链。

🟡 **[The Decoder]** xAI 削减 Grok Bot 配额，马斯克承认成本「相对收入不可持续」 — 上周末多名用户发现每周额度腰斩，有人等数天才能恢复；Grok Bot 与 Grok、Cursor 共享额度，可浏览网页、回邮件、登录账号。同期 OpenAI 从 12 月起合并 Codex 与 ChatGPT 额度，Anthropic 则表示一个 Agent 的成本是普通对话的 4 到 15 倍——平价 Agent 订阅正在集体退潮。

🟡 **[OpenAI]** OpenAI 启动 Grid Protectors 计划，未来园区可在电网紧张时削减最多 1 吉瓦负荷 — 相当于约 70 万户家庭的用电量。公司称将与电力公司、监管机构协商每个园区可削减的规模、响应速度与持续时间，先在佐治亚州落地，把「可调节用电」做成数据中心的设计标准。

⚪ **[OpenAI]** OpenAI 发布 LifeVal 基准，衡量 AI 处理日常事务的真实能力 — 覆盖找托育、家庭理财、政府文书等生活场景，试图把评测从考试题和代码题拉回普通人真正会交给 AI 的任务。

## 💡 今日洞察

1. **Agent 的「平价包月」正在集体退场。** Grok Bot 额度腰斩、OpenAI 12 月合并 Codex 与 ChatGPT 额度、Anthropic 承认 Agent 成本是聊天 4–15 倍——三家在同一个月做同一件事，说明补贴换增长的阶段结束了，接下来是按量计费、配额分层和「谁的 Agent 单位任务成本更低」的工程竞赛。
2. **AI 基建进入「举债 + 并购」阶段。** Oracle 发 200 亿美元股票与债券、Marvell 千亿美元吞下 Lumentum、Anthropic 背 8950 亿美元算力承诺——算力从巨头的现金游戏变成资产负债表游戏，风险开始向信贷和并购市场传导，这也是高盛这类机构同时收紧 AI 工具权限的底层背景。
3. **优化对象正在从 prompt 转向模型内部。** 权重空间编程让 LLM 直接读懂并改写权重，Qwen4 用新架构压低单位智能成本，阿里披露的 RSI 已能自主迭代 33 轮——三条线指向同一个方向：下一轮竞争不再只是「怎么问」，而是「怎么改模型本身」。
