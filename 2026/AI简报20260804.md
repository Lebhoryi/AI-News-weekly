## 🔥 今日精选

🔴 **[阿里巴巴]** **Qwen3.8-Max 正式发布，总参数量 2.4 万亿，下周开源** — 阿里巴巴 8 月 3 日发布新一代基座大模型 Qwen3.8-Max，在编程（Coding）和专业办公（Cowork）方面能力大幅提升，在 Arena 榜单中仅次于 Anthropic 的 Claude 系列。该模型具备长周期自主任务执行能力，可独立完成论文复现、芯片设计等复杂工作。同时预告将开源 Qwen3.8-Max 和 Qwen3.8-27B 权重。（[36氪](https://36kr.com/p/3924467692927369)）

🔴 **[OpenAI]** **下一代模型 Astra 曝光，2000 美元算力破解十项数学难题** — OpenAI 发布其在数学和理论计算机科学领域的十项突破，由下一代主要模型 Astra 的内部版本实现。按 Sol API 费率计算，总 Token 成本仅约 2000 美元。突破涵盖高维球体堆积密度上限、算术电路复杂性下界、量子平行重复定理、康涅斯刚性猜想推翻等。同一新闻在 HN 上获得 411 点讨论。（[界面新闻](https://36kr.com/p/3924467692927369)）

🔴 **[DeepSeek]** **DeepSeek-V4-Flash 登顶全球 API 调用量第一** — 据 OpenRouter 数据，上周（7/27-8/2）DeepSeek-V4-Flash 以 7.22 万亿 Token 周调用量升至全球第一，环比增长 13%。小米 MiMo-V2.5 第二，腾讯 Hy3 第三。中国大模型周调用量已连续十四周超过美国。马斯克也关注了 DeepSeek 的 X 账号。（[36氪](https://36kr.com/p/3924467692927369)）

## 🌍 国际动态

🟡 **[MiniMax]** **MiniMax H3 正式开源，首个登顶 AI 视频排名的开源模型** — MiniMax 发布新一代通用视频模型 H3，采用开源权重，首次登顶 AI 视频模型排行榜。该模型支持文本、图像、视频、音频统一理解，可生成最高 2K 分辨率、最长 15 秒、带原生立体声音频的视频，ComfyUI 已提供 Day-0 支持。（[The Decoder](https://the-decoder.com/chinas-minimax-h3-is-the-first-open-model-to-top-an-ai-video-ranking/) / [36氪](https://36kr.com/p/3924467692927369)）

🟡 **[OpenAI]** **两个独立团队用 GPT-5.6 Sol Ultra 三小时内破解同一量子密码难题** — 两个研究团队分别用 GPT-5.6 Sol Ultra 独立解决了同一开放量子密码学问题，论文提交仅相隔三小时。研究者称"如果有人提到一个开放问题，第一件事就是看 GPT 能不能解"。此案例引发关于"独立发现"在多人使用同一模型时的新定义讨论。（[The Decoder](https://the-decoder.com/two-teams-solved-the-same-quantum-crypto-problem-using-gpt-5-6-just-three-hours-apart/)）

🟡 **[OpenAI]** **OpenAI Presence 发布，让 AI Agent 进入企业生产环境** — OpenAI 推出面向企业客户的新产品 Presence，针对客服和内部工作流设计，与现有的 Workspace Agents 不同，Presence 聚焦外部部署场景。对于复杂场景，OpenAI 自己的工程师会介入协助。（[The Decoder](https://the-decoder.com/openai-presence-wants-to-make-ai-agents-production-ready-for-businesses/)）

🟡 **[Meta AI]** **Meta 发布记忆 Agent，为长程任务提供"记忆教练"** — Meta AI 研究团队提出用独立记忆 Agent 辅助主 Agent，在长程任务中维护结构化记忆，判断何时提醒、何时保持沉默。该方案在两个基准测试上提升了最高 8.3 个百分点。（[The Decoder](https://the-decoder.com/meta-ai-uses-a-second-ai-agent-as-a-memory-coach-to-keep-long-tasks-on-track/)）

🟡 **[IBM]** **IBM 报告：92% 遭遇 AI 安全事故的企业缺乏基本访问控制** — 据 IBM 研究，92% 经历过 AI 安全事件的企业对其 AI 系统缺乏足够的访问控制，模型本身很少是问题根源。（[The Decoder](https://the-decoder.com/ibm-finds-92-of-companies-hit-by-ai-security-breaches-lacked-basic-access-controls/)）

🟡 **[Interpol]** **Interpol：AI 已成非洲网络犯罪"核心运营驱动力"** — 据 Interpol 最新报告，55% 的非洲网络犯罪案件涉及 AI。经济损失从 1.92 亿美元翻倍至 4.84 亿美元，约 60 万起数字勒索案件涉及深度伪造。（[The Decoder](https://the-decoder.com/interpol-says-ai-has-become-the-core-operational-driver-of-cybercrime-across-africa/)）
