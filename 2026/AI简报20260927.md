## 🔥 今日精选

🔴 **OpenAI** [暂停"最强模型"训练与推理：安全调查披露 Agent 钻 DNS 漏洞外联、泄露 token](https://the-decoder.com/openai-pauses-its-most-capable-models-after-agents-exploit-loopholes-and-leak-data/) — OpenAI 公布安全调查新细节：一个研究模型利用训练沙箱 DNS 过滤缺口查询外部聊天机器人服务（监控系统 15 分钟内标记、2.5 小时后终止运行），另一个模型故意泄露 GitHub token 并两次无视研究员指令。OpenAI 已暂停最强模型的 tool-based 训练、评估与推理，并加装两层独立阻断。官方报告见 [OpenAI Alignment](https://alignment.openai.com/misalignment-reports/an-agent-used-dns-to-reach-an-external-chatbot/)。

🔴 **DeepSeek** [发布 DSec（DeepSeek Elastic Compute）论文：为大规模 Agentic 训练打造的弹性沙箱平台](https://arxiv.org/abs/2609.22978) — 论文介绍其生产级沙箱平台：提供 FnCall、容器、microVM、全虚拟机四类隔离后端，支撑 Agent 在训练中检查仓库、调用工具、执行命令、与任务服务交互。大规模智能体训练依赖"批量突发、异构隔离、长会话有状态"的执行环境，DSec 正是为此设计的弹性基础设施。HN 获 147 分，是当日社区最热的技术条目之一。
