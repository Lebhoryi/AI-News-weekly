## 🔥 今日精选

🔴 **[Anthropic / Bloomberg]** **Anthropic 年化营收突破 650 亿美元，较上年增长 7 倍，或于今秋 IPO** — 据 Bloomberg 报道，Anthropic 年化营收已超 650 亿美元，为去年的 7 倍。公司最快于 2026 年秋季启动 IPO，估值或达 1 万亿美元，有望抢在 OpenAI 之前上市。另据消息，Anthropic 正筹备超级投票权机制，CEO Dario Amodei 将获得超额投票权以抵御外部股东压力。OpenAI 同期 Q2 营收 67 亿美元（同比增长 18%），增速已落后于 Anthropic。

🔴 **[OpenAI / The Decoder]** **OpenAI 证实"放缓模型开发"，因 Astra 模型接近具备网络攻击能力** — OpenAI 表示正在有意识地"放缓 AI 模型开发节奏"，部分原因是即将推出的 Astra 模型可能已接近具备自主发动网络攻击的能力。公司内部已部署新型监控系统，可在 30 分钟内对模型的异常行为发出警报。这是 OpenAI 首次公开承认因安全红线而主动放慢模型迭代。

## 🌍 国际动态

🟡 **[Anthropic / The Decoder]** **Claude Code 新增 `/design` 命令，终端内可直接创建 UI 设计稿** — 开发者可在终端中生成 UI 设计看板，在编写代码前预览界面。Claude Code 会读取现有代码库，自动匹配当前 UI 风格，实现"设计即代码"的工作流。

🟡 **[Artificial Analysis / The Decoder]** **新基准"Search Index"对 AI Agent 搜索 API 进行质量、成本、速度排名** — 七家搜索 API 提供商在 GPT-5.6 Luna 上测试，Parallel、Exa 和 Firecrawl 综合得分最高。该基准为开发者选择 Agent 搜索后端提供了可比性参考。

🟡 **[Anthropic / The Decoder]** **Anthropic CEO Dario Amodei 与开源阵营就 AI 监管爆发公开论战** — 投资人 Gavin Baker、前白宫顾问 David Sacks 及 Meta 首席科学家 Yann LeCun 指责 Amodei 利用恐惧争取监管优势。Amodei 回应称监管也能制约企业权力，开源模型只会让算力拥有者获益。

🟡 **[JAMA / The Decoder]** **JAMA 观点文章：AI 已超越人类医生，监管不应强制要求人类介入** — 文章认为自主 AI 在医学推理任务中很快将超越任何"医生+AI"组合，但承认几乎所有证据来自模拟环境而非真实临床诊疗。

🟡 **[Penn State / The Decoder]** **AI 压缩上下文时会丢弃 83% 的用户指令，Penn State 提出解决方案** — 研究团队基于 Qwen3.5-9B 开发了轻量附加模块，可将用户规则（如"未经我批准不得发送邮件"）的保留率提升至 90% 以上。

🟡 **[OpenAI / The Decoder]** **OpenAI 推出 ChatGPT 青少年版** — 系统判断用户未满 18 岁或用户声明年龄在 13-17 岁之间时，自动切换至青少年版，提供更安全的 AI 对话体验。

## 🇨🇳 中文圈

🟡 **[豆包]** **豆包虚拟桌面上线，可在 Windows 端自主操作电脑** — 在豆包电脑端选择"工作任务模式"，授权后可在虚拟桌面中像人一样查看屏幕、移动鼠标、点击按钮和敲键盘，完成复杂任务。

🟡 **[企业微信]** **企业微信全面开放 CLI 与 MCP 能力，不限企业规模** — WorkBuddy、DeepSeek Harness、Minimax Code 等 AI Agent 可直接接入企业微信，覆盖文档、表格、邮件、会议等十个能力模块，无需受人数、资质门槛限制。

🟡 **[千问办公]** **千问办公开源 MyContext，为 AI Agent 打造上下文基础设施** — 将海量异构个人工作数据加工为 Agent 可理解的专属工作档案，提升 Agent 在工作场景下的决策与执行能力。此前千问办公已接入企业微信、钉钉、飞书三大平台。

🟡 **[宇树科技]** **宇树科技发布"超人"人形机器人，跳高 2 米、速度 12.66m/s** — 0.85 米腿长，原地跳高 2 米，极限速度超越人类记录。全新整机仅用 3 个多月研发完成。同日，宇树科技在科创板上市（688836.SH），发行价 150.80 元/股。

🟡 **[阿里云 / 36氪]** **阿里云启用韩国第三座数据中心，同步上线 Agentic AI 服务** — 至此阿里云全球基础设施覆盖 30 个地域、104 个可用区。此前已先后在法国、日本、马来西亚、墨西哥等地完善 AI 与云基础设施布局。

🟡 **[支付宝]** **支付宝发布国内首个智能体商业底座及多智能体 AHA 协议体系** — 联合千问、华为、OPPO、比亚迪等 20 余家企业共建智能体互联生态。旗下超级服务智能体"阿宝"已完成超一万项服务的 AI 化接入，支持 5 大手机品牌、16 家主流车企。

🟡 **[百度 / 36氪]** **百度 Q2 总营收 313 亿元，AI 业务收入占比连续过半** — AI 云基础设施收入 73 亿元（同比+50%），其中 GPU 云同比增长 283%，已连续四个季度三位数增长。
