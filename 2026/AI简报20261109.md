## 🌍 国际动态

🟡 **[Apiiro / Hacker News]** Claude Code 的「Yes, and don't ask again」把数据库密码写进了公开仓库 — 安全公司 Apiiro 扫描 GitHub 上 104,185 份 `.claude/settings.local.json`，发现 1,122 份含真实密钥，共在 1,994 个公开仓库里找到 2,539 个真实凭证：生产库密码、云厂商管理员密钥、Square 生产 token、某医疗记录库的属主密码，涉及 63 个组织；另有 1,160 个藏在 git 历史、团队有意提交的 `settings.json` 和 agent 聊天记录里。Claude Code 负责人 Boris Cherny 已在 HN 回应，称团队正在原型"自动模式拦截 + 基础密钥扫描"。（[原文](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)）

🟡 **[The Decoder / Co-Design Bench]** 新基准给编码 agent 泼冷水：最强的 GPT-6 Astra 也只有 26.4% 的任务全对 — 阿里与多所亚洲高校用真实用户改动需求构建 Co-Design Bench，让 agent 改造现有 Web 应用，输入还包含图片、音频、视频和文档。GPT-6 Astra 平均满足约 70% 的需求点，但完全正确的只有 26.4%；作者指出旧基准已被"模型能自己跑、自己查、自己改"刷到 99% 以上，所以分数崩塌不是模型退步，而是考题终于变真了。（[论文](https://arxiv.org/abs/2610.35138)｜[原文](https://the-decoder.com/ai-coding-agents-still-need-human-cleanup-on-nearly-three-out-of-four-tasks-in-a-real-world-test/)）

🟡 **[Bernstein / 新浪财经]** 伯恩斯坦：OpenAI 到 2030 年算力支出约 6140 亿美元，低于市场流传的 7500 亿 — 分析师 Mark Moerdler 按已披露的算力合作协议测算，前提是所有合同按期执行；实际数字可能因数据中心延期、项目取消和硬件采购调整而减少或推迟。市场对 AI 资本开支的"预期通胀"，正在被卖方一点点挤水分。

⚪ **[The Decoder / X]** Karpathy 用一个周末做出 HackerTube：Claude Opus 5.5 把 Hacker News 二十年攒下的 4300 万条评论筛成 6,454 个"值得反复被推荐"的视频 — 站点不登录、不做精修封面、只截视频中段一帧，Karpathy 称观看体验明显好过 YouTube 自己的推荐；随后他又用 Claude Code "三分钟一把过"做出收录 47,000 个视频的 TristanTube。他手动做的只有申请 GCP 密钥、租服务器和买域名。（[原文](https://the-decoder.com/andrej-karpathy-built-a-curated-video-platform-in-a-weekend-using-claude-and-20-years-of-hacker-news/)）

## 🇨🇳 中文圈

🟡 **[arXiv / 每日经济新闻]** 苹果人形机器人方案里的"中国底座"：Qwen 双模型 + 宇树 G1 + 一台 Mac mini — 苹果研究团队 11 月 4 日提交的 HALO 论文显示，系统用冻结的 Qwen3.5-2B 作视觉语言编码器，把第一视角图像和自然语言指令压成联合特征，再由 DiT 解码器输出动作；上层 orchestrator 直接在本机跑 Qwen3.6-35B-A3B（4-bit、MLX）。整机是宇树 G1，头部加装 OAK-1W 相机、背部塞一台 64GB 的 Mac mini M4 Pro，全程无线。在 6 个未预先建图的真实家庭里做了 360 次单任务测试，成功率 91%；组合任务平均 70%，"俯身过障碍—走向目标—推箱子"只有 50%。（[论文](https://arxiv.org/abs/2611.06908)｜[代码](https://github.com/apple-aiml-research/ml-halo)）

🟡 **[澎湃 / 界面]** 启元机器人第 10000 台个人机器人下线，14 天从 5000 台翻到 1 万台 — 上纬新材旗下启元 10 月才正式量产，产能爬坡速度是这条新闻真正的信息量：Q1 身高 88cm、全身 22 个柔顺力控自由度、可折叠放进背包，官方称月活超 98%、日均在线峰值超 40%、人均每天交互 100 多次。消费级具身智能第一次有了"万台"量级的交付数字。

## 💡 今日洞察

1. **资本和治理在同时收紧。** Anthropic 的估值从 2 万亿一路退到 1.2 万亿，标普 500 科技板块远期市盈率 17 倍、九年来首次低于大盘的 18 倍；另一边英伟达在财报前两周被董事会立案调查。2026 年下半年的主题不再是"AI 能做什么"，而是"AI 资产值多少、谁为它负责"。
2. **Agent 的信任边界正从"模型能力"转向"权限设计"。** 高盛把编码 agent 收回给工程师、Apiiro 在 1,994 个仓库里翻出 2,539 个真实密钥、Co-Design Bench 显示四分之三的任务仍需人工收尾——三件事指向同一个结论：落地的瓶颈已经从智商变成"谁能用、能碰什么、出事谁兜底"。
3. **中国供应链在海外方案里的位置变了。** 苹果的人形机器人用 Qwen 做感知与编排、用宇树 G1 做本体、用一台 Mac mini 跑推理，说明中国模型与中国硬件已经进入美国一线实验室的默认选型；而国内消费级机器人先跑出"万台"交付，规模优势仍在制造端。
