🔴 **[澎湃新闻 / 科创板日报]** DeepSeek 下一代大模型 V5 计划基于华为昇腾芯片预训练 — 澎湃从 DeepSeek 方面确认，V5 将是其首款原生依托昇腾 950 训练的大模型；此前昇腾芯片主要承担 DeepSeek 模型的推理任务。昇腾 950 系列分 950PR 与 950DT，均基于第三代达芬奇架构，面向训练与推理场景。若按计划落地，这将是国产旗舰大模型第一次把预训练全流程放在国产算力上，而不只是拿国产卡做推理或微调。（[新浪财经转载](https://finance.sina.com.cn/jjxw/2026-11-03/doc-inixnitq9873453.shtml)）

## 🌍 国际动态

🟡 **[Claude / The Decoder]** Anthropic 上线 Message Threads，长对话首 token 时间降约 35% — 此前每次 API 请求都要重发整段对话历史，Message Threads 只传上次之后新增的部分，在 50 万～100 万 token 的请求上首 token 时间降低约 35%。线程在两次请求之间以加密形式驻留内存，闲置 5 分钟过期；由于 Claude 仍需读取完整历史，token 计费不变。受益最大的是编程 Agent、computer-use Agent 和大量文档/图像处理流程，已在 Claude 平台及 AWS、Microsoft Foundry、Google Cloud 上线公测。（[The Decoder](https://the-decoder.com/anthropics-message-threads-cut-time-to-first-token-by-35-percent-for-long-conversations/)）

🟡 **[NVIDIA / SETI]** Allen 望远镜阵列交给 AI Agent 控制与实时分析信号 — SETI 研究所与 Breakthrough Listen 在加州北部的 Allen Telescope Array 部署基于 NVIDIA Holoscan 的系统，实时吞吐最高 2.4 Tbps，过去需要数周的工作现在数小时完成。早期成果之一是用 AI 实时探测到蟹状星云中的一颗脉冲星，团队称这是首次。目前指令仍由研究人员输入，下一步想验证可本地运行的边缘开源方案，为未来月球背面传感器做准备。（[The Decoder](https://the-decoder.com/ai-agents-take-over-at-setis-allen-telescope-array-scanning-for-extraterrestrial-intelligence/)）

🟡 **[The Information]** 英伟达要求部分云客户少接中国业务，并披露最终用户 — 这项指引不具强制性、只针对未来合同，通过销售代表和区域团队口头传达，目标是让云厂商（包括英伟达扶持的 neocloud）客户结构更分散。它堵的是出口管制的一个缺口：规则限制芯片出货，却基本不管通过境外云服务远程租用算力。美国方面此前已在调查中国 AI 公司经海外数据中心获取先进芯片的情况，其中涉及 Kimi 背后的月之暗面。（[The Decoder](https://the-decoder.com/nvidia-pushes-cloud-customers-to-cut-back-on-china-business/)）

🟡 **[The Information]** 华为让客户自己去找 AI 芯片所需 HBM，采购被推入黑市 — 华为计划明年初推出昇腾 960DT，号称性能翻倍，但国内供应商产不出足够的高带宽内存，而美方规则又挡住三星、SK 海力士（两家合计占全球 80% 以上份额）的直接供货。走私网络利用规则漏洞，把 HBM 与低端处理器捆绑、经香港转运入境，黑市单颗价格被推到约 4000 美元；韩国海关到 5 月已查获 5.6 亿美元违规交易，超过去年全年纪录。（[The Decoder](https://the-decoder.com/huawei-tells-customers-to-find-their-own-ai-chip-memory-effectively-outsourcing-procurement-to-the-black-market/)）

🟡 **[Stanford / The Decoder]** 50 条被广泛引用的 LLM 结论里，44% 已经「过期」 — 斯坦福研究者 Owen Queen 与 James Zou 把 50 条高引结论放到 20 个当前模型上复测：44% 已失效，另有 34% 明显减弱；在有预估失效期的 22 条里，平均寿命只有 15.7 个月。失效最快的是「模型做不到 X」这类否定性结论，而模型之间的差距即便在同一代内也依然很大。（[The Decoder](https://the-decoder.com/rapid-llm-development-is-outrunning-the-research-meant-to-explain-it-study-finds/)）

## 💡 今日洞察

1. **模型的交付物正在变成「工件」。** Astra 一周交出的是外壳 + PCB + 固件，而不只是代码；权重空间编程交出的是改过的权重。一旦输出从文本换成可被制造、被加载的东西，验收标准就会从「像不像」变成「能不能用、公差够不够」，这也是 OpenAI 那几轮返工的真正含义。
2. **算力地缘正在从「买卡」转向「买训练」。** 英伟达堵境外云租用、华为把 HBM 采购推给客户、DeepSeek 计划用昇腾 950 做预训练，三件事同一天出现在新闻里：管制在向下游延伸，国产替代则从推理层挤进预训练层，谁先把旗舰模型训出来，谁才有资格谈生态。
3. **研究的半衰期只有 15.7 个月。** 今天被引用的「模型做不到 X」，明年大概率不成立。对做选型和采购的人来说，榜单和论文结论都该标上「有效期」，单位任务成本和实际交付质量这类随工程沉淀的指标，反而更耐用。
