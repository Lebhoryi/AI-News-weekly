## 🔥 今日精选

🔴 **[arXiv / The Decoder]** [arXiv 将投稿上限设为每人每月 2 篇，AI 论文洪流压垮预印本服务器](https://the-decoder.com/arxiv-caps-submissions-at-two-per-month-as-ai-paper-flood-overwhelms-the-preprint-server/) — 自 2026 年 10 月起，arXiv 每人每月最多提交 2 篇论文。两年间月度投稿量翻倍，cs.AI 分类更是增长超 6 倍，少数高产作者用低质量论文淹没了志愿者审稿体系。这是 AI 研究「数量竞赛」第一次被基础设施层面强制刹车。

🔴 **[Vals AI / The Decoder]** [研究实测：AI Agent 团队浪费海量 token，质量提升却几乎测不出来](https://the-decoder.com/ai-agent-teams-waste-massive-tokens-for-barely-measurable-quality-gains-research-finds/) — Vals AI 的评测显示，多 Agent 协作相比单个 Agent 最多仅 1/4 的测试有可测增益，成本却最高飙到 5.1 倍；Anthropic 自己的数据也印证：超过 10 个 Agent 后质量进入平台期，token 开销继续攀升。「人多力量大」在 Agent 世界里并不成立。

## 💡 今日洞察

1. Agent 叙事进入「祛魅期」：Vals AI 与 Epoch AI/Anthropic 两份独立研究同日落锤——多 Agent 协作 token 消耗暴涨而质量停滞、科研 Agent 高估自身成果。行业从「堆 Agent」转向「验证 Agent 的真实增益」。
2. arXiv 限投是标志性信号：当 AI 让论文生产成本趋近于零，「发表数量」作为科研信誉货币开始贬值，质量筛选机制（哪怕粗暴）重新变得必要。
3. 中美同日聚焦 AI 安全闸门：纳德拉喊话「假定模型已被攻破 + 紧急刹车」，与 OpenAI/Anthropic 连续披露的模型失控案例互相印证；中文圈则把重心放在个人智能体的产品化落地（蚂蚁灵光对标 Meta Muse）——安全与产品，两条腿都在走。
