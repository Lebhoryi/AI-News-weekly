## 🌍 国际动态

🟡 **[Anthropic / The Decoder]** **Claude Code 默认启用 Auto Mode** — 8月14日起，Pro/Max/Team 套餐的 Claude Code 将默认启用自动模式。安全分类器能拦截 89% 危险命令，而人工审查仅能发现 13.6%。开发者角色加速从写代码转向监控 AI 输出。 [详情](https://the-decoder.com/anthropic-sets-claude-code-to-auto-mode-by-default-to-protect-developers-from-bad-approvals/)

🟡 **[Google DeepMind / The Decoder]** **DiffusionGemma 发布：无需从头训练即可构建文本扩散模型** — 基于 Gemma 4 改造，仅用不到 10% 的原始训练预算，实现 256 tokens 并行生成（约 1500 tokens/s），但推理任务质量仍不及原版自回归模型。 [详情](https://the-decoder.com/googles-diffusiongemma-proves-you-dont-need-to-train-from-scratch-to-build-a-text-diffusion-model/)

🟡 **[Google DeepMind / The Decoder]** **WeatherNext 同时预测气旋路径和强度** — 新的 AI 气象模型比当前领先的运行模型提前约 1 天预测热带气旋，相当于传统气象预报十年进步。代码和模型权重在 GitHub 开源。 [详情](https://the-decoder.com/google-deepminds-weathernext-predicts-cyclone-tracks-and-intensity-at-the-same-time/)

🟡 **[Anthropic / The Decoder]** **Claude Code 会话间支持跨终端通信** — macOS 和 Linux 上并行运行的 Claude Code 实例可互相发送消息、共享上下文和检查状态。 [详情](https://the-decoder.com/claude-code-sessions-can-now-talk-to-each-other-and-share-context-across-terminals/)

🟡 **[The Decoder]** **Nvidia 与 Amazon 投入数十亿建设 AI 电力基础设施** — Nvidia 投资高达 30 亿美元于电力基础设施开发商 Lancium（已在德州签约 4GW 项目）；Amazon 在德州建设 7.65GW 燃气电厂，年碳排放可达 3300 万吨。AI 的能源需求正推动史无前例的电力投资。 [详情](https://the-decoder.com/ais-energy-appetite-drives-nvidia-and-amazon-to-pour-billions-into-massive-power-infrastructure/)
