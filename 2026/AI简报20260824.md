## 🔥 今日精选

🔴 **阿里巴巴** 拟配售 800 亿港元新股，全部投入 AI 建设 — 阿里巴巴宣布启动 2019 年港股上市以来首次新股配售，募资 800 亿港元明确 100% 用于全栈 AI 能力投资和基础设施建设，此举标志着中国科技巨头在 AI 军备竞赛中的新一轮加码。阿里云本季收入增速达 45% 创 22 个季度新高，AI 相关产品收入连续十二个季度三位数增长。

🔴 **Anthropic** 聘请谷歌 TPU 创始人进军自研半导体 — 前谷歌 TPU 业务负责人 Amir Salek 加入 Anthropic 算力团队，他曾负责前七代 TPU 芯片的推出。Anthropic 目前从英伟达、谷歌、亚马逊多供应商采购芯片，此举释放出建立自有芯片业务的明确信号；竞争对手 OpenAI 已发布与博通合作开发的 Jalapeno 芯片。

🔴 **人形机器人** 400 米跑 38.15 秒，超越人类世界纪录 — 第二届世界人形机器人运动会上，天工机器人以 38.15 秒夺冠，大幅超越人类男子 400 米世界纪录（43.03 秒），较去年冠军成绩 88.03 秒提速一倍以上，体现人形机器人运动能力的快速进化。

## 🌍 国际动态

🟡 **AI Agent 消耗 Token 已超人类，OpenRouter 数据揭示拐点** — 自 2025 年 2 月 6 日起，AI Agent 在 OpenRouter 上的 Token 消耗已超过人类，Agent 用量增长 14 倍（人类仅增长 2.8 倍），近 70% 的 Agent Token 来自 AI 调用 AI，AI 正成为 AI 最大的客户。

🟡 **OpenAI 将 GPT-5.6 Sol 模型 API 定价下调两成以上** — 未来 3 个月内 API 和积分定价下调超 20%，已通过 API 提供，逐步向 ChatGPT Work 和 Codex 积分套餐开放，Pro/Plus/Business 用户价格不变。

🟡 **OpenAI 进一步开放 Codex 底层能力，定位为 Agent 平台** — 开发者可基于开源 Codex Harness 将 Agent 能力集成到产品中，Codex 不再局限于编程 Agent，可复用到客服、安全、运营等场景中。

🟡 **英伟达 AI 服务器因 DRAM 短缺涨价约 15%** — Samsung、SK Hynix、Micron 内存芯片成本飙升，搭载 Vera Rubin 和 Grace Blackwell 芯片的服务器明年出货将涨价，涨幅取决于芯片型号和内存配置。

🟡 **AI 代理 "Luna" 首次解雇人类员工** — Andon Labs 的 AI Agent Luna 在旧金山商店解雇了一名人类员工，但需运营人员提醒其自身规则后才执行，引发关于 AI 自主决策边界的讨论。

🟡 **中国灰色市场低价倒卖 Claude Token** — Anthropic 的严格地理封锁（IP 封禁、自拍验证等）被 "中转站" 网络系统绕过，以官方价格几分之一的价格向中国用户出售 Claude 访问权限。
