## 🔥 今日精选

🔴 **DeepSeek** DeepSeek 发布 V4-Flash-Vision-Exp 实验性多模态模型 — 在保留 V4-Flash 纯文本能力（Agent、推理、世界知识）的基础上，新增图像理解能力。在 DeepSeek 自研的多模态 Agent Benchmark 上，表现已接近 Opus 4.8，部分指标甚至超越。这是 DeepSeek 在视觉 Agent 赛道的重要布局，已通过 API 开放服务。（[The Decoder](https://the-decoder.com/deepseek-releases-experimental-flash-vision-model-that-rivals-opus-4-8-on-agent-benchmarks/)）

🔴 **OpenAI** OpenAI 进一步开放 Codex 底层能力，将其定位为通用 Agent 平台 — 开发者可基于开源的 Codex Harness 将 Agent 能力集成到自有产品中，不再局限于编程场景。Codex Harness 支持将模型能力接入客服、安全、运营等业务场景，使同一套 Agent 运行机制可跨场景复用。同时 OpenAI 将 GPT-5.6 Sol 模型 API 定价下调 20% 以上。（[36氪](https://36kr.com/p/3949992200928641)）

## 🌍 国际动态

🟡 **Anthropic** Anthropic 将最强模型 Claude Mythos 5 投入网络安全防御 — 使用 Claude Security 扫描代码库漏洞，提供 CWE 分类严重性评级和补丁建议，并已接入合作伙伴的网络安全产品以保护关键基础设施。（[The Decoder](https://the-decoder.com/anthropic-puts-its-most-powerful-model-claude-mythos-5-to-work-for-cyber-defense/)）

🟡 **Waymo** Waymo 自主研发现代化芯片用于 Robotaxi，减少对 Nvidia 的依赖 — 这是自动驾驶公司自研芯片的重要信号，标志着行业成熟度提升和垂直整合趋势加速。（[The Decoder](https://the-decoder.com/waymo-builds-its-own-chip-for-its-robotaxis-cutting-its-reliance-on-nvidia/)）

🟡 **Netflix** Netflix 测试自研语言模型 GenRec 替代人工推荐逻辑 — 将用户观看行为转为纯文本输入，与多年积累的传统推荐引擎对垒并获得更好结果。Netflix 称其为"早期但有希望的尝试"。（[The Decoder](https://the-decoder.com/netflix-tests-language-model-as-alternative-to-hand-built-recommendation-logic/)）

🟡 **研究** 普林斯顿大学 & UC San Diego 研究揭示 AI Agent 的"Skills"机制 — 研究发现 Skills 让 Agent 变强主要源于结构化工作流，而非知识增量。但 Skills 库膨胀后，Agent 找到正确指令集的难度也会增加，存在规模瓶颈。（[The Decoder](https://the-decoder.com/study-explains-why-ai-agents-benefit-from-skills-and-when-they-fail/)）

🟡 **研究** 新研究提出"心理世界模型"框架 — 当前世界模型（如 Sora、Genie）仅模拟物理世界，忽略人类信念、意图和情感。加入心理变量后，即使较弱的语言模型也能超越更强的传统世界模型。（[The Decoder](https://the-decoder.com/world-models-that-ignore-human-beliefs-predict-the-wrong-actions-new-research-shows/)）

🟡 **政策** 美国拟要求盟友在 AI 竞争中选边站 — 据路透社报道，美国正在起草致伙伴国家的信函，要求其在中美 AI 竞争中做出选择，AI 地缘政治博弈持续升温。（[The Decoder](https://the-decoder.com/us-wants-to-force-partner-countries-to-choose-between-washington-and-beijing-in-the-ai-race/)）

## 🇨🇳 中文圈

🟡 **雷鸟创新** 雷鸟 iO AI 眼镜正式发布，首发 1996 元起 — 该产品不配备摄像头，主打文字叠加和全天候主动式 AI 助理，整机仅 34g，支持 DeepSeek V4 Pro 与千问 3.7 Max 等多模型，续航两天。雷鸟创新 2026 年 Q1 位居中国及全球 AR 眼镜出货量第一。（[36氪](https://36kr.com/p/3950603951258756)）

🟡 **科大讯飞** 科大讯飞宣布将于今年全球 1024 开发者节推出全新主力通用大模型 — 基于全国产算力训练，8 月底先出阶段性版本。目标在代码能力和 Token 性价比上达到国内第一梯队，全国产算力训练大模型中保持领先。（[36氪](https://36kr.com/p/3946071687921026)）

🟡 **阿里云** 阿里巴巴发布 2027 财年 Q1 财报，阿里云增速创 22 季度新高 — AI 相关产品收入连续第 12 个季度实现三位数同比增长，经调整 EBITA 同比增长 133%，EBITA 利润率增至 12%。资本支出 676.78 亿元，同比增长 75%，主要用于 AI 基础设施建设。（[36氪](https://36kr.com/p/3949992200928641)）

🟡 **苹果** 苹果裁撤至少 60 名 Vision Pro VR 团队员工，战略重心转向 AI 眼镜 — 据传苹果 AI 眼镜预计 2027 年 WWDC 亮相，同年上市。此前报道苹果还计划在 Siri 和 Vision Pro 团队裁员超 200 人。（[36氪](https://36kr.com/newsflashes/3950185027501440)）

🟡 **豆包** 豆包上线"技能·连接器·工作伙伴"新模式 — 电脑版侧边栏可直接使用，内已上架超 200 个技能和连接器，支持自定义新建技能，标志着豆包从对话工具向 Agent 平台演进。（[36氪](https://36kr.com/newsflashes/3948826792115589)）

🟡 **机器人** 2026 世界机器人大会（WRC）报道：上半年全球人形机器人出货量突破 2.2 万台，同比增长近 300% — 智元、宇树、银河通用、优必选、乐聚位列前五，均为中国厂商。但娱乐表演和数据生产研究合计仍占出货量 60% 以上，距离工厂大规模应用仍有距离。（[36氪](https://36kr.com/p/3950374720306563)）
