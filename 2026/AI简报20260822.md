## 🔥 今日精选

🔴 **DeepSeek** 发布实验性多模态模型 V4-Flash-Vision-Exp，在 Agent 基准测试中接近并有时超越 Opus 4.8 — DeepSeek 在 V4-Flash 文本能力基础上增加了图像理解能力，这是其 Flash 系列首次获得多模态支持。实验性模型已可通过 API 访问，标志着 DeepSeek 在多模态 Agent 赛道的重大突破。（[The Decoder](https://the-decoder.com/deepseek-releases-experimental-flash-vision-model-that-rivals-opus-4-8-on-agent-benchmarks/)）

🔴 **Nvidia** 以 60 亿美元收购 AI 初创公司 Poolside 的 "Model Factory" 平台及 109 名员工 — 该平台用于构建和训练 AI 模型，Nvidia 通过此次收购进一步强化其从硬件到模型训练基础设施的完整生态布局。（[The Decoder](https://the-decoder.com/nvidia-is-acquiring-poolsides-model-factory-and-109-employees-for-6-billion/)）

🟡 **OpenAI** 为 GPT-Image-2 添加透明背景生成能力 — 通过 API 预览，Alpha 通道在图像生成时直接内嵌，据称效果优于传统背景移除方案。（[The Decoder](https://the-decoder.com/openais-gpt-image-2-can-now-generate-images-without-a-background/)）

🟡 研究显示 AI 提高作业成绩但导致考试成绩下降 — 《经济学人》报道的一项研究发现，使用 AI 辅助的学生作业分数提升，但考试分数却出现下滑，引发对 AI 教育工具「依赖性」的担忧。（[HN](https://news.ycombinator.com/item?id=49394496)）
