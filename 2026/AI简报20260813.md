## 🔥 今日精选

🔴 **DeepSeek V4 Pro 0813 正式版上线** — DeepSeek 发布 V4 Pro 0813 版本，在 OpenRouter 等平台上线，HN 社区 720 分热议。新版本在多项基准上与 GPT-5.5 Pro 竞争，同时 DeepSeek 宣布即将大幅涨价，建议用户提前规划用量。([OpenRouter](https://openrouter.ai/deepseek/deepseek-v4-pro-0813))

🔴 **xAI 发布 Grok 4.6，以极低成本追平前沿** — Grok 4.6 在 Artificial Analysis Intelligence Index 上得 61 分，与 GPT-5.6 Sol 持平，仅次于 Claude Opus 5（63 分）。定价 $2/$6 每百万 token，比 Claude Opus 5（$5/$25）和 GPT-5.6 Sol（$5/$30）便宜 60%+。在 Agentic 任务上表现尤为突出，仅需约 53 步完成复杂工作流。([The Decoder](https://the-decoder.com/spacexais-grok-4-6-matches-openais-best-model-and-undercuts-it-on-price/) | [Artificial Analysis](https://artificialanalysis.ai/articles/grok-4-6-benchmarks-and-analysis))

🔴 **Qwen3.8-2.4T-A95B 权重开放发布** — 阿里 Qwen 团队在 HuggingFace 上发布 Qwen3.8-2.4T-A95B 模型权重，总参数量 2.4 万亿，激活参数 950 亿。此前 Qwen3.8-Max 已在 Agentic Index 上被评为最佳模型，权重开放将进一步推动开源应用。([HuggingFace](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B))

## 🌍 国际动态

🟡 **OpenAI 发布 ChatGPT Linux 桌面版** — OpenAI 正式推出 ChatGPT Linux 桌面应用，补齐桌面端生态空缺，覆盖 Linux 开发者群体。([The Decoder](https://the-decoder.com/openai-launches-chatgpt-desktop-app-for-linux/))

🟡 **Nvidia 推进 Nemotron 4 万亿参数模型** — 英伟达正在开发 Nemotron 4，最大版本将达至少 1 万亿参数，为 Nemotron 3 Ultra 的两倍。但这一规模已被中国实验室超越：Moonshot AI 的 Kimi K3 达 2.8 万亿参数，Qwen3.8 达 1.6 万亿。英伟达已将内部训练云支出增至 2031 年前 280 亿美元。([The Decoder](https://the-decoder.com/nvidias-nemotron-4-aims-for-one-trillion-parameters-a-scale-chinese-labs-already-surpassed/))

🟡 **Anthropic 任命首位法律业务负责人** — 法律科技初创创始人 Robert Mahari 加入 Anthropic，担任首位"Head of Claude for Legal"，负责在律师事务所和法律部门部署 Claude。([The Decoder](https://the-decoder.com/legal-startup-founder-robert-mahari-joins-anthropic-to-lead-claudes-push-into-law-practices/))

🟡 **Google Gemini 市场份额持续流失** — 三家数据源一致显示 Gemini 市场份额从 12% 降至 1.9%，OpenAI 保持 50%+，Anthropic 从 4.3% 增长至 14.9%。Similarweb 和 OpenRouter 数据均确认此趋势。([The Decoder](https://the-decoder.com/googles-gemini-is-losing-market-share-to-chatgpt-and-claude-according-to-new-market-data/))

🟡 **微软 MAI Code 1.1 Flash 被 DeepSeek 全面碾压** — 微软发布 MAI Code 1.1 Flash 代码模型，号称 token 效率提升 25%、成本降至 1/4，但在基准测试中被更便宜的 DeepSeek V4 Flash 超越。([The Decoder](https://the-decoder.com/microsofts-new-mai-code-1-1-flash-gets-crushed-by-deepseek-on-both-price-and-performance/))

🟡 **研究实现 LLM 提示词逆向工程** — IIT Bombay 和 Adobe Research 开发出"前文预测"方法，可从 LLM 输出以近完美精度重建原始提示词，无需访问模型权重，对 AI 安全和内容溯源有重要启示。([The Decoder](https://the-decoder.com/researchers-can-now-reverse-engineer-llm-prompts-from-output-text-with-near-perfect-accuracy/))
