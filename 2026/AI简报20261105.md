## 🔥 今日精选

🔴 **[Moonshot / Hugging Face]** Kimi K3.1 Pro 完整权重开源，2.8T 参数、104B 激活 — 月之暗面按 10 月发布时的承诺放出权重，这是目前体量最大的开放权重模型：MoE 总参数 2.8T、每 token 激活 104B、93 层、896 个专家取 16 个、上下文 1,048,576 token，视觉编码器为 401M 的 MoonViT-V2，原生支持文本与图像。权重以 MXFP4（激活 MXFP8）的量化感知训练形式发布——16bit 等值约 5.6TB，量化后体积大幅压缩，直接面向可部署性。官方自报 Terminal-Bench 4.0 得 65.7、SWE Marathon v1.1 得 51.7、BenchCAD 带工具 92.7，与 Claude Opus 5.5（66.4 / 46.3 / 96.2）、GPT-6 Astra（58.2 / 42.5 / 95.9）互有胜负。HN 上「Kimi K3.1 Pro model weights are out」已拿到 350 分左右。（[Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)）

🔴 **[腾讯混元 / 科创板日报]** 混元 Hy4 正式版发布：770B 参数，首次引入视觉理解与电脑操作 — 相比 8 月的 Hy4 preview，预训练与后训练规模显著扩大，官方称 Hy 系列首次跻身最强开源模型之列，同时承认与 GPT-6.1 Sol、Claude Opus 5.5 仍有明显差距。Computer Use 让模型能结合命令行与图形界面操作 Blender、CAD 等专业软件，并针对跨应用长程任务做了专项训练；视觉侧可做细粒度图像处理、复杂图表分析与数学视觉推理。定价与 preview 持平：输入 6 元、输出 18 元每百万 tokens，缓存命中 0.3 元；权重将于近期开源，Hy5 预计年底到明年初。（[科创板日报](https://www.cls.cn/detail/2525324)）

## 🌍 国际动态

🟡 **[Ricursive / HN]** Ripple-65B Preview 开源：65B 稠密模型拿下美国开放权重 agentic coding 最好成绩 — 12T token 预训练、支持 1M 上下文，TerminalBench 2.1 得 80.52，高于体量大得多的 Reflection Beam 501B（80.1）、Meta Muse Spark Open 816B（76.4）、Thinking Machines Inkling 975B（63.8）与 NVIDIA Nemotron 3 Ultra 550B（56.4）。团队称从零到发布的全套研发成本仅 3200 万美元，约为上一代开放权重 SOTA 的十分之一，稠密小参数结构还能在 DGX Spark 这类本地设备上跑。（[原文](https://www.ricursive.com/ripple)）

🟡 **[OpenAI]** OpenAI 收购 Pierre Computer Company，为 Agent 并行写代码补 Git 工具链 — Pierre 的 Trees（快速文件导航）、Diffs（直接在 diff 视图里改 bug）、Highlights（实时语法高亮）三个开源库已驱动 Codex，Code Storage 则用 Git 存储代码与历史。OpenAI 此前已自建版本控制后端 Pando，这笔交易指向同一件事：当多个 Agent 并行改代码，Git 的合并与审计模型需要重做。开源项目保持开源，交易仍待监管批准。

🟡 **[Anthropic]** Anthropic 开源 FlashProve：用 zkSNARK 证明「这条回答确实出自这个模型」 — 提供方先对权重做数字指纹，之后每次输出附一份不泄露权重的紧凑证明。在 400B 的 Llama 4 Maverick 上，单张 H100 约 110 tokens/s 生成证明，每份约 19MB，普通 CPU 17 秒可验完，开销约为正常推理的 70～95 倍——比此前同类开源系统（1000 token 要 14 小时、93.6GB 证明）快了几个数量级。限制也很硬：目前只支持 1024 token 以内上下文，且只在模型选最可能的下一个 token（贪心解码）时成立。（[技术报告](https://www.anthropic.com/document/flashprove-technical-report)）

🟡 **[密歇根大学 / The Decoder]** CloudOpsBench 开源：运维 Agent 的主要瓶颈是判断力，不是知识 — 45 个真实 AWS 运维任务（修服务、删资源、收权限、灰度发布、下线项目），最好的 Claude Fable 5.1 只过 60%，GPT-6 Astra 53%。约 80% 的失败源于误判任务范围、没检查完相关服务、过早收工；另 20% 是错误操作，其中一部分对基础设施不可逆。同一套任务可在真实 AWS 与模拟器上复跑，GCP/Azure/OCI 版本在计划中。（[GitHub](https://github.com/CloudOpsBench/CloudOpsBench)）

🟡 **[OpenAI]** ChatGPT 支持用 Images 2.6 直接生成循环 GIF — 输入文字或上传照片即可产出，还能调速度、逐帧修改；官方演示的「跳舞的猫」靠的是跨帧角色一致性，早几代模型帧间变化太大，做不出这种翻页动画效果。开发者侧同步上线 API 模型 GPT-Image-2.6「Flare」（主打效率）与「Sunburst」（主打质量）。OpenAI 称 ChatGPT 与 API 每周生成图片已超过 40 亿张，比 9 月多出 10 亿。

🟡 **[Google / NYT]** 2027 年起学校关掉 Google 的 AI，就等于关掉搜索 — Gemini、Gemini Notebook 与 Search 将对学生账号默认关闭，需学校逐项开启；但「不带 AI 的搜索」不再提供，负责教育的副总裁 Chris Phillips 称搜索与 AI 已融合到无法拆开。学校可二选一：带完整 AI 概览与对话的搜索，或把学生引向「Guided Learning」引导模式。纽约、洛杉矶两大校区 9 月已限制学生用 AI，洛杉矶明确想保留无 AI 概览的搜索，被 Google 拒绝。

## 💡 今日洞察

1. **开源旗舰的比拼项从「分数」换成了「可部署性」。** Kimi K3.1 Pro 用 MXFP4 把 2.8T 参数压到能实际搬运的体量，Hy4 把价格钉在 6/18 元并承诺很快开源权重。榜单第一名三个月就会换人，但量化格式、许可条款和每百万 token 的价格，才决定别人能不能真的用起来。
2. **参数效率正在重新变成卖点。** Ripple-65B 用 3200 万美元、65B 稠密参数打赢 501B～975B 的美国开源同行，说明在 agentic coding 这类任务上，「配方 + 数据 + RL」的杠杆比单纯堆参数更大——对小团队来说，这是比追万亿参数更现实的路。
3. **Agent 落地的瓶颈是边界，不是智力。** CloudOpsBench 里 80% 的失败来自范围误判、漏查服务和过早收工；字节的新规把管控从「工具入口」挪到「数据出口」；OpenAI 买 Pierre 是为了让多个 Agent 并行改代码时 Git 还能用。三件事的共同点是：能力已经够用，缺的是让它在边界内可靠运行的工程与治理。
