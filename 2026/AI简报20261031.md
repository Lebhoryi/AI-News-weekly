## 🔥 今日精选

🔴 **开源模型自主攻击力实证**：Epoch AI 研究显示，开源模型 GLM 5.3 仅凭公开安全补丁，在 48 小时内零人工输入构建出完整的 Firefox 浏览器攻击链，自主攻破 6 个 Firefox 版本，每次攻击的 API 成本仅约 1000 美元，且未被任何被测试厂商的安全机制拦截。（GLM 5.3 是智谱 2026 年的旗舰开源模型，此次研究首次量化了开源模型在真实漏洞利用上的自主能力）[来源](https://the-decoder.com/open-weight-model-glm-5-3-built-full-firefox-exploit-chains-with-zero-human-input-in-under-48-hours/)

🔴 **Claude Code 恶意扩展事件**：一个被篡改的 Claude Code 扩展在 Cursor 插件市场上存活约 11 小时，尝试窃取用户数据并建立远程访问，影响用户约 5000 人。Cursor 紧急将整个市场下线审查后重新上线。该事件在 Hacker News 引发 758 分、473 条讨论，是近期最受关注的 AI 供应链安全事件。[源头分析](https://phorion.io/blog/offical-claude-code-vsx-compromise/)：[Decoder 报道](https://the-decoder.com/malicious-claude-code-extension-in-cursors-marketplace-attempted-remote-access-and-data-theft/)
