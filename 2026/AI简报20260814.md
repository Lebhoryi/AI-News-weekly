## 🔥 今日精选

🔴 **DeepSeek V4 Pro 正式版上线 + 开源 Harness v0.1 Agent 框架** — DeepSeek 将其旗舰模型 V4 Pro 从测试阶段转为正式版，同时以 MIT 协议开源了 agent 软件 Harness v0.1，并同步上调 API 价格（缓存命中价格涨至 6 倍）。这是 DeepSeek 在模型能力与开发者生态上的双重推进。([来源](https://the-decoder.com/deepseek-launches-an-improved-v4-pro-model-raises-api-prices-and-makes-its-agent-software-open-source/))

🔴 **Google Gemini 3.7 Flash 发布** — 距 3.6 Flash 仅三周，Gemini 3.7 Flash 在编程和 agent 任务上大幅提升，定价比前代低 50%，Google 自称其编程能力超越 Claude Sonnet 5 和 GPT-5.6 Terra。([来源](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/))

🔴 **Cerebras + OpenAI 推出 GPT-5.6 Sol Ultrafast 模式** — Cerebras 为 OpenAI 提供超快推理服务，Sol Ultrafast 模式最高可达 750 tokens/s 且无质量损失，首批面向特定客户开放。([来源](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai))

## 🌍 国际动态

🟡 **Ling 3.0 Flash 发布** — 蚂蚁集团 inclusionAI 发布，在 Artificial Analysis Intelligence Index 上得分 38，与 Qwen3.6 27B 相当但活跃参数更少，幻觉率从 97% 降至 44%，以 MIT 协议开源。([来源](https://the-decoder.com/ling-3-0-flash-is-the-smartest-open-model-at-its-size/))

🟡 **Anthropic Claude Cowork 进入 Chrome 扩展** — Claude Cowork 现可在 Chrome 侧边栏直接运行，首次支持 skills、plugins 和 connectors，无需额外配置即可在浏览器中完成研究到生成 Excel/PPT 的工作流。([来源](https://the-decoder.com/anthropic-brings-claude-cowork-to-its-chrome-extension-adding-skills-and-plugins-to-the-browser/))

🟡 **Suno Studio 2.0 发布** — Suno 将 AI 音乐平台升级为完整制作工具，聊天即可创建乐器与插件，支持 MIDI 导入和 32-bit 无损导出，面向 Premier 订阅用户。([来源](https://the-decoder.com/suno-studio-2-0s-new-chat-feature-lets-you-talk-to-your-daw-like-its-a-bandmate/))

🟡 **Mistral OCR 4.1 发布** — Mistral 推出新一代 OCR 模型，在文档识别精度上进一步提升。([来源](https://docs.mistral.ai/models/ocr-4-1))

🟡 **Fable 5 企业采用率仅 6%** — 据 Ramp 数据，Anthropic 最强模型 Fable 5 仅占 Anthropic 总 token 销售的 6%，高昂定价表明企业为前沿 AI 付费意愿已达天花板。([来源](https://the-decoder.com/fable-5s-slow-adoption-suggests-corporate-willingness-to-pay-for-frontier-ai-has-hit-a-ceiling/))
