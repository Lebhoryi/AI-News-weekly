## 🔥 今日精选

🔴 **英伟达发布 Nemotron 3.5 Lightning 开源模型 + 5000 亿美元基础设施融资** — 英伟达连续发布两项重磅消息：Nemotron 3.5 Lightning 仅 3.6B 活跃参数，开源权重，在指令遵循上匹敌 OpenAI 的 gpt-oss-120b，同时推出 NeMo Switchyard 路由库支持从边缘到数据中心的多场景部署；此外，英伟达联合 Apollo、BlackRock、Blackstone、Brookfield、Goldman Sachs 和 KKR 六大机构，通过芯片价值担保机制撬动超 5000 亿美元 AI 基础设施融资。

🔴 **Anthropic 全面部署 C2PA 隐形水印 + 91 亿美元数据中心签约** — Anthropic 宣布自 8 月起所有 Claude 输出嵌入 C2PA 标准隐形水印，经编辑后仍可检测，这是迄今为止最广泛的大模型内容溯源部署；同时与比特币矿企 Riot Platforms 签署 91 亿美元数据中心租约，在得克萨斯州建设大规模算力设施，为 IPO（预计 9-10 月）做准备。

🔴 **字节跳动成立 AI 数据与安全一级部门** — 字节跳动新设 AI 数据与安全一级部门，与 Seed、Flow 并列，由王赢磊（Adam Wang）负责，标志着字节 AI 战略从模型研发向数据基础设施和安全纵深推进。

## 🌍 国际动态

🟡 **OpenAI 推出 $125/月 Premium Seats** — ChatGPT Business 新增高级席位，定价为标准的 5 倍，配备更大上下文窗口和更高调用限额，应对 Agentic AI 场景下的高 token 消耗。([the-decoder.com](https://the-decoder.com/openai-introduces-125-premium-seats-for-chatgpt-business-as-agentic-ai-burns-through-more-tokens/))

🟡 **安全研究：从闭源 LLM API 窃取推理痕迹** — 安全研究人员发现 OpenAI、Anthropic、Google 的 API 存在漏洞，可通过特定手段提取加密的推理过程痕迹，包括"but marinade"等奇怪文本片段和泄露的密码。([the-decoder.com](https://the-decoder.com/but-marinade-and-leaked-passwords-are-what-researchers-found-in-chatgpts-hidden-reasoning/))

🟡 **OpenAI 完成 700 亿美元员工股票回购** — OpenAI 允许现任和前任员工以 8520 亿美元估值出售股票，这是迄今为止规模最大的 AI 公司二级交易之一。([the-decoder.com](https://the-decoder.com/openai-lets-employees-cash-out-another-7-billion-in-stock/))

🟡 **Mojo 1.0 正式发布** — Modular 发布 Mojo 1.0 版本，这是面向 AI/ML 基础设施的高性能编程语言里程碑，支持 Python 生态兼容性和系统级性能优化。([modular.com](https://www.modular.com/blog/modular-26-5-mojo-1-0-is-here))

🟡 **Anthropic 超级 IPO 面临投资者质疑** — 据 WSJ 报道，Anthropic 计划 9-10 月上市，可能成为史上最大科技 IPO 之一，但投资者对中国竞争对手（如 DeepSeek）和政治不确定性表示担忧。([the-decoder.com](https://the-decoder.com/anthropics-planned-mega-ipo-faces-investor-skepticism-over-chinese-rivals-and-political-headwinds/))
