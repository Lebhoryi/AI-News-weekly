🟡 **[The Decoder]** **xAI 发布 Imagine Image 2.0 图像生成器** — 为 Grok 推出的新模型在 Arena 基准测试中排名第二，仅次于 OpenAI 的 GPT-Image-2，新增 Magic Wand 和多参考编辑等工具。

🟡 **[The Decoder]** **研究显示 AI Agent 能耗比普通聊天高 600 倍** — 气候科学家 Zeke Hausfather 跟踪 8 周 Claude Code 使用：消耗 32 亿 token、约 170 kWh 数据中心电力，每提示词能耗约为普通 AI 聊天的 600 倍。

🟡 **[The Decoder]** **Claude Code 实现跨会话通信** — 在 macOS 和 Linux 上，并行运行的 Claude Code 实例可互相发送消息、共享上下文和检查彼此状态。
